### whoami

I build and run **PXN Stores LK**, a Sri Lankan digital-goods store. The product is a VPN, and I own every layer of it — the Android and Windows clients, the storefront customers buy from, the reseller portal my partners sell through, the admin console I operate from, and the automation that delivers an order without me touching it.

Solo operator. The servers are real, the customers are real, and it is my phone that rings when a tunnel drops.

### What I actually run

| Surface | What it does | Built with |
| :-- | :-- | :-- |
| **PXN Shield · Android** | VLESS client with in-app store, live usage and account login | Kotlin · v2rayNG core |
| **PXN Shield · Windows** | Desktop client on a pinned v2rayN 7.22.5 core | C# · WPF + WebView2 |
| **Storefront** | Catalogue, checkout, instant delivery | React · Vite · Supabase |
| **Reseller portal** | Partner provisioning, wallets, tiers, public REST API | React · Deno edge functions |
| **Admin console** | Fleet, orders, finance, support, analytics | React · TanStack Query |
| **Delivery pipeline** | Provision, renew, expire, alert — no human in the loop | Deno · Postgres · pg_cron |

Panel fleet across Singapore and Colombo on Xray/VLESS, with per-customer routing so a Sri Lankan package genuinely exits in Sri Lanka.
